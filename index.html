☁️ Koneksi Database Cloud (Neon.tech PostgreSQL) 🟢 Terhubung / Siap

Dirancang untuk 200 - 500+ siswa ujian serentak dengan teknologi Serverless & PgBouncer Connection Pooling (Anti-Deadlock).

🚀
Arsitektur Serverless Hybrid: Data utama selalu tersimpan aman di peramban (Offline First). Ketika dihubungkan ke Neon.tech, seluruh data siswa, pengerjaan, dan jawaban auto-save otomatis tersinkronisasi ke PostgreSQL Cloud 24/7 tanpa risiko server down.
⚡ Ingin Cepat & Praktis?
Salin 1 baris utuh postgresql://... dari Neon, lalu klik tombol di samping.
⚠️ Peringatan Host: Host Neon wajib diawali dengan ep-... (contoh: ep-cool-fog-123456.ap-southeast-1.aws.neon.tech). Jangan hanya memasukkan ap-southeast-1.aws.neon.tech.
Format wajib: ep-[nama-unik].ap-southeast-1.aws.neon.tech (tersedia di widget Connection Details Neon).

🔄 Sinkronisasi Penuh 2-Arah (Web ⇄ Neon Cloud)

Tarik seluruh akun Guru & Pengawas, Master Siswa, serta Jadwal dari Neon ke web sekaligus amankan data lokal ke cloud secara serentak.

Kapasitas 200 - 500+ Siswa Serentak

📖 Panduan Menyiapkan Neon.tech dalam 3 Menit (Gratis 24/7)

  1. Kunjungi console.neon.tech dan klik Sign In with GitHub.
  2. Buat project baru (misal: zettcbt-sdn14), pilih region Asia Pacific (Singapore - ap-southeast-1).
  3. Buka menu SQL Editor di Neon, buka file neon_schema.sql di folder aplikasi ini, salin seluruh isinya, lalu klik tombol Run.
  4. Salin Host (contoh: ep-cool-fog-123456.ap-southeast-1.aws.neon.tech) dan Password dari dashboard Neon ke form di atas, lalu klik Simpan & Uji Koneksi. Selesai!

TATA TERTIB & INTEGRITAS UJIAN ONLINE

SD NEGERI 14 TOBOALI • Aturan Disiplin & Sistem Anti-Curang

⚠️
PERINGATAN KERAS BAGI SELURUH PESERTA: Seluruh pergerakan layar, perpindahan tab, dan aktivitas ujian diawasi ketat oleh Sensor Anti-Curang Realtime dan tercatat langsung ke server pengawas!
Pasal 1 Kemandirian & Kejujuran Mutlak

Ujian ini dilaksanakan untuk mengukur kemampuan diri sendiri secara jujur dan mandiri. Segala bentuk kerja sama antar siswa, bertanya kepada teman, menyontek, menggunakan catatan ringkasan/buku, atau dibantu oleh pihak lain dilarang keras.

Pasal 2 Larangan Pindah Tab & Keluar Aplikasi

Peserta DILARANG KERAS meminimalkan jendela ujian, beralih/membuka tab peramban lain, membuka aplikasi luar (seperti WhatsApp, Google, Chat GPT / AI, kalkulator, YouTube), atau menekan tombol navigasi beranda (Home/Recent Apps).

Pasal 3 Sensor Otomatis & Sirine Alarm Pengawas

Sistem dilengkapi Page Visibility Sensor. Saat layar berpindah tab atau aplikasi ditutup, sistem seketika membunyikan Sirine Alarm, memicu peringatan layar merah pada perangkat, dan langsung mengirimkan laporan pelanggaran realtime ke monitor pengawas ruang.

Pasal 4 Toleransi Maksimal 3 Kali Peringatan (Auto-Lock)

Sistem menerapkan batas toleransi pelanggaran maksimal 3 (tiga) kali:

  • Pelanggaran Ke-1: Peringatan keras layar merah di perangkat peserta.
  • Pelanggaran Ke-2: Peringatan terakhir & nama siswa ditandai merah di dashboard monitor pengawas.
  • Pelanggaran Ke-3: 🚨 SISTEM TERKUNCI OTOMATIS (AUTO-LOCK) dan lembar ujian diselesaikan paksa (AUTO-SUBMIT). Ujian dinyatakan gugur seketika!
Pasal 5 Larangan Fitur Layar Terbagi (Split-Screen)

Dilarang menggunakan fitur layar terbagi (Split Screen), pop-up view, floating app, atau dual screen pada smartphone dan tablet. Tampilan ujian harus selalu berada dalam mode layar penuh (Full-Screen).

Pasal 6 Pemblokiran Copy-Paste, Screenshot & Inspect

Sistem secara ketat memblokir fungsi klik kanan (context menu), blok seleksi teks, salin-tempel (Ctrl+C, Ctrl+V), tangkapan layar (screenshot/screen recorder), serta fitur Inspect Element/Developer Tools.

Pasal 7 Sanksi Diskualifikasi & Pemanggilan Orang Tua

Peserta yang terbukti sengaja menyontek atau melanggar tata tertib akan langsung dikenakan sanksi disiplin resmi:

  1. Pembatalan hasil ujian dan diberikan NILAI 0 (NOL) pada mata pelajaran bersangkutan.
  2. Pemanggilan resmi orang tua / wali murid oleh pihak Kepala Sekolah dan Tim Ketertiban Sekolah.
  3. Pencatatan sanksi pelanggaran moral dan disiplin pada buku rekam jejak akademik siswa.
